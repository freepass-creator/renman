# 차량360 규격서 — `/vehicle/[plate]` 상세패널 규격 이식

> 사장님 확정 2026-08-06. **이 문서만 읽고 한 번에 재작성한다.** 조각 전환 금지(화면이 섞인다).

## 0. 목적

**360에 들어오면 그 자산에 대한 것을 확실하게 본다** — 자산 1대의 계약이력·모든 이력을 한 화면에서.

## 1. 규격 (다른 원장 상세패널과 동일)

- **접히는 섹션** + 그 안에 **표**. 그게 전부다.
- 고정값 = **KV 표**(라벨|값 한 줄씩) · 여러 건인 이력 = **섹션 안 작은 표**
- 탭 분리 아님. 카드(`ObjCard`)·지표(`Metric`)·`Cards` 나열 전부 폐기
- 신호는 **값의 색**으로만. 박스·행틴트 금지
- 섹션 제목 옆 **건수 배지**(`count`)로 접힌 채로도 몇 건인지 보인다

### 이미 준비된 것 (재사용 — 새로 만들지 말 것)

| 있는 것 | 무엇 |
|---|---|
| `LedgerRecordSection.body` | 섹션 안에 표를 넣는 자리 (`components/ui/record-panel.tsx`) |
| `LedgerRecordSection.count` | 제목 옆 건수 배지 |
| `ASSET_DETAIL_DEFS` / `ASSET_DETAIL_SECTIONS` | 차량 KV 정의표 (`lib/master-ledger-cols.tsx`) — 등록·상태 / 등록증정보 / 제조·제원 … |
| `.ledger-record-panel__section` | 섹션 접기 CSS (`app/globals.css`) |

## 2. 섹션 매핑 — 현재 14블록 → 규격

| 규격 섹션 | 종류 | 현재 출처 | 유지할 기능 |
|---|---|---|---|
| 등록·상태 | **KV** | `ASSET_DETAIL_DEFS` | — |
| 등록증 | **KV** | `v-reg` (InfoDoc) | **서류 등록·변경(업로드+OCR)** |
| 제조·제원 | **KV** | `v-info` + `ASSET_DETAIL_DEFS` | **수정(인라인 편집)** |
| 취득·할부 | **KV** | `v-purchase` | 편집 · 상환표는 아래 표로 |
| 보험 | **KV** | `v-insurance` (InfoDoc) | **증권 업로드+OCR · 수정** |
| 운영·상품 | **KV** | `v-product` · `v-gps` | 상품등록 · **시동 제어/해제** |
| 자산 손익 | **KV** | `v-econ` | — |
| **계약이력** | **표** | `v-schedule`(pastContracts) | 행 클릭 → 계약 딥링크 |
| **수납 스케줄** | **표** | `v-schedule`(현재계약) | 미납 강조 · 미수관리 딥링크 |
| **할부 상환** | **표** | `v-purchase` 내 스케줄 | 잔여 표시 |
| **정비·사고** | **표** | `v-work` | **+수선/작업 등록** |
| **과태료** | **표** | `v-penalty` | 상태전이 버튼 · 변경부과 공문 |
| **손바뀜** | **표** | `v-handover` | — |
| **활동이력** | **표** | `v-history` | **+기록(QuickLogForm)** |
| 보증금 정산 | KV | `v-deposit` | 정산 실행 |

**섹션이 아닌 것 (그대로 둔다):**
- 상단 신분행(상태 배지·차명·회사) · **미결·리스크 칩**(패널 헤더 배지 역할)
- **CTA = 하단 고정 액션바**(`LedgerPanelFooter` 자리): 계약중 = 반납·연장·중도해지 / 유휴 = 인도

## 3. 각 표의 열 (확정)

| 표 | 열 |
|---|---|
| 계약이력 | 기간 · 계약자 · 월대여료 · 종료사유 · 미수 |
| 수납 스케줄 | 회차 · 기한 · 청구 · 수납 · 미납 · 상태 |
| 할부 상환 | 회차 · 납기 · 원금 · 이자 · 잔액 |
| 정비·사고 | 일자 · 구분 · 내용 · 업체 · 금액 · 상태 |
| 과태료 | 위반일 · 내용 · 실운전자 · 기한 · 금액 · 처리상태 |
| 손바뀜 | 기간 · 계약자 · 인수/반납 |
| 활동이력 | 일자 · 구분 · 내용 · 작성자 |

- 금액 열 = `align:'r'` · `sortNum` · `xf:'money'` (엑셀 규격 동일)
- 빈 값 = `LEDGER_EMPTY.dash`

## 4. 완료 기준

1. `Cards` · `Metric` · `ObjCard` 가 `VehicleDetail.tsx` 에서 **0개**
2. 위 §2 의 「유지할 기능」이 전부 살아 있다 — 특히 **등록증·보험 업로드**, 제원 편집, 시동 제어, +수선, +기록
3. `tsc 0` · `vitest` 전건 · `/vehicle/[plate]` 200
4. 모바일(`useIsMobile`)에서도 섹션이 접히고 표가 가로 스크롤된다

## 5. 주의

- **업로드 경로를 지우지 말 것.** 등록증·보험증권을 붙일 수 있는 유일한 상시 화면이 여기다(오픈 조건 ①).
  `InfoDoc` → `pushDocVersion(type:'vehicle'|'insurance')` 가 정합성 검사(`doc-crosscheck`)의 근거다.
- `useVehicleDetail` 훅(510줄)은 **건드리지 않는다.** 데이터·액션은 그대로 두고 **표시층만** 바꾼다.
- 현황 섹션은 **이미 KV 로 전환 완료**(2026-08-06 `ed511be`). 나머지 이력 블록이 남았다.
