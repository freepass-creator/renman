# RENMAN UI·UX 공용 규격

## 적용 범위

운영 화면은 기능 이름이 아니라 행동 문법으로 통일한다. `/dev/*` 디자인 실험 화면과 다른 경로로 즉시 이동하는 폐기·호환 라우트는 검수 대상에서 제외한다.

- 원장 화면: `LedgerFrame` → 회사·검색·필터 → 통계 → 보기 → 도구 → 주 액션
- 행 상호작용: 한 번 클릭은 선택, 더블클릭은 우측 `LedgerRecordPanel`
- 수정·신규: 우측 `LedgerEditPanel`·`LedgerCreatePanel`
- 모바일: 데스크톱 표의 축소판이 아니라 `mobileCard` 전용 뷰. 기본/전체 열 전환을 노출하지 않는다.

## 컨트롤 문법

| 행동 | 공용 원자 | 규칙 |
|---|---|---|
| 저장·등록·실행 | `Btn` | 패널마다 solid 주 액션은 하나. 보조는 ghost, 삭제는 danger |
| 아이콘 실행 | `Btn iconOnly` | 반드시 `tip` 제공 |
| 표·카드 안 이동 | `TextLink` | 손으로 border:none 버튼을 만들지 않는다 |
| 단일 선택 | `PillTabs` | 같은 높이·활성색·선택 진동 사용 |
| 복수 선택 | `ToggleChips` | 체크 의미가 아닌 빠른 필터·복수 분류에 사용 |
| 한 줄 입력 | `Input` | 날짜·금액·일반 문자열 모두 크기 체계 공유 |
| 여러 줄 입력 | `TextArea` | 보더·포커스·폰트는 Input과 동일, 세로 크기만 가변 |
| 드롭다운 | `Select` | 공용 화살표·패딩·높이 사용. 네이티브 `<select>` 직접 사용 금지 |
| 기능 메뉴 | `ActionMenu` | `출력 ▼`처럼 여러 실행을 묶을 때 사용. 외부 클릭·ESC·방향키·모바일 44px 항목을 공통 처리 |
| 검색 | `Search` | 검색 아이콘·지우기 버튼 포함. 자동완성 검색은 전용 컴포넌트 허용 |
| 세부 필터 | `LedgerFilterButton/Panel/Fields` | 필터 수·활성 필터·초기화 위치 통일 |
| 파일 투입 | `FileDrop` | 보이는 파일 투입 UI를 페이지에서 손으로 만들지 않는다 |

## 크기·배치

- 웹 기본 32px, 원장 툴바·칩 28px, 모바일 터치 컨트롤 44px.
- 우측 상세패널의 헤더·행 보조 액션과 조밀한 행 입력은 `sm`, 본문 폼 입력과 최종 실행은 기본 크기를 사용한다.
- 드롭다운은 값 선택에는 `Select`, 여러 기능 실행에는 `ActionMenu`를 사용하며 두 역할을 시각적으로 섞지 않는다.
- 모바일 입력 폰트는 16px로 고정해 iOS 자동 확대를 방지한다.
- 툴바 순서와 상세패널의 헤더·본문·푸터 구조는 페이지별로 바꾸지 않는다.
- 버튼 라벨은 행동형으로 쓴다: `저장`, `확인·매칭`, `담당·기한`, `필터 초기화`.
- 상태값과 행동 신호를 섞지 않는다. 예: 업무상태와 `기한경과`는 별도 표시한다.

## 직접 HTML 허용 예외

- 공용 원자 내부 구현
- 숨겨진 파일 입력, 체크박스·라디오
- 검색 자동완성 결과행, 트리행, 접기 헤더처럼 일반 버튼과 역할이 다른 복합 위젯
- 오류 경계처럼 공용 UI 번들 자체가 실패했을 때도 보여야 하는 최소 복구 화면

일반 입력·드롭다운·여러 줄 입력을 직접 HTML로 만드는 것은 금지하며 `tests/ui-consistency.test.ts`에서 검사한다.
