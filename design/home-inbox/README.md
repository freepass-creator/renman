## 5. 지금 코드로 옮기면 (Cursor 요청문 초안)

1. **목록 행 = `HomeProblem` 그대로.** `action`→조치, `plate·who·amount·dday·assignee·company`→나머지 칸. 새 셀렉터 없음.
2. **섹션 = `dday` 판정 하나.** `group==='미납' || dday<0` → 지연 · `dday===0` → 오늘 · `1~7` → 이번 주 · 그 밖 → 예정(접힘). `domainOf`는 칩 필터.
3. **사람 필터** = `assignee === me` / 미배정 / 전체.
4. **수행 탭** = 같은 `plate`의 열린 `HomeProblem` + work_item. 완료·접수·연기 = `docs/PLAN-work-autogen.md`의 제안행 지연 실체화 그대로. 근거키 `auto:{종류}:{대상}:{기한}` = work_item 문서ID, 패널 메타에 그대로 노출(감사 추적).
5. **차량360 탭** = 기존 Vehicle360(`lib/detail-sections.ts` 전체 섹션 + history)을 수행창 폭에 맞춰 렌더. 별도 페이지·링크 없음. 차량 없는 건(자금 미분류)은 「자금」 탭 = 입금 후보 표.
6. **모바일** = `/m` 홈만 교체(목록). 수행창 = `/m/vehicle/[plate]`를 수행 | 차량360 2탭으로 재구성.
7. **완료 · 오늘** 섹션 = 오늘 완료된 work_item(취소선). 하루의 진행이 보여야 피드백이 닫힌다.

## 6. 열린 질문(사장님 판단)

- 첫 앱 이름: 「업무」(제안) vs 확정 IA의 「업무조회」. 조회가 아니라 수행이라 「업무」를 권함.
- 「내 업무」 기본값: 직원은 「내 업무」, 본사(HQ)는 「전체」로 시작하는 게 맞는지.
- 「연기」 기본 기간(1주/2주) · 연기한 건이 「예정」으로 갈지 「이번 주」 끝으로 갈지.
- 본(bone) 배경 채택 여부.
- (해소) 차량 360은 별도 페이지가 아니라 수행창의 두 번째 탭 — 사장님 확인. 남은 것: `/vehicle/[plate]` 직접 진입(검색·URL) 시에도 같은 수행창 레이아웃으로 열지.
