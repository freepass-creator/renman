업무 — 목록과 수행창 v3 · UI 세련·샤프

홈은 조회 화면이 아니라 오늘 처리할 업무가 도착해 있는 자리다. 왼쪽 목록에서 고르면 오른쪽 수행창(360)이 열리고, 거기서 완료·접수·연기·기록까지 끝낸다. 수행창은 「수행」·「차량360」 두 탭뿐 — 할 것과, 그 차량의 전부. 모바일은 목록 페이지 → 수행창 페이지. v3 — 카드·틴트를 걷어내고 흰 면 + 헤어라인, 라운드 4/6, 잉크색 주버튼, 아웃라인 컨트롤, 목록 열 헤더, 행 36px, 쿨 뉴트럴. 빨강은 미수 금액에만.

구조 — 목록 · 수행창

목록은 ERP가 감지한 문제를 조치 단위로 번역해 놓은 업무다. 행의 앞머리는 차량번호가 아니라 조치(「내용증명 발송 · 31마7702」). 묶는 축은 지연 · 오늘 · 이번 주 · 예정 — 언제 하나. 어디 문제인가(미수·차량·재무)는 칩.

수행창의 탭은 둘: 수행 = 이 대상에 지금 할 것(선택한 업무 + 같은 대상의 다른 열린 업무 + 빠른 기록 + 최근 이력), 차량360 = 그 차량의 전부(현재 상태 6칸 + 시간순 이력, 상위집합). 별도 「차량 360 →」 링크는 없다 — 탭이 곧 360이다.

모바일은 같은 두 화면이 페이지 전환으로 이어진다. 목록 → 누르면 수행창(수행 | 차량360) → 뒤로.

v3 시각 규칙 (샤프)

  • 면은 흰색 하나. 구분은 1px 헤어라인(#e2e5ea / 약 #edeff2)로만. 카드·틴트 박스 없음.
  • 라운드 4px(컨트롤) · 6px(면). 그림자 없음.
  • 주버튼 = 잉크색. 보조 = 1px 아웃라인. 세그먼트·칩도 아웃라인. 브랜드색은 마크에만.
  • 목록에 열 헤더(조치 · 대상 · 계약자·차명 · 금액 · 기한 · 담당). 행 36px. 숫자는 전부 tabular.
  • 섹션·라벨은 10.5px · 자간 .04em. 위계는 크기 대신 굵기·자간·색.
  • 빨강은 미수 금액과 지연 기한에만. 지출 금액(과태료·세금)은 잉크. 주황 = 오늘·미배정. 초록 = 완료.
  • 선택 = 좌측 2px 잉크 바 + 옅은 회색. 탭 = 2px 밑줄.

지금 코드로 옮기면

  • 목록 행 = HomeProblem 그대로: action이 조치, plate·who·amount·dday·assignee가 나머지 칸.
  • 섹션 = dday 하나로 판정: 미납 또는 dday<0 → 지연 · 0 → 오늘 · 1~7 → 이번 주 · 그 밖 → 예정.
  • 수행 탭 = 같은 plate의 열린 HomeProblem+work_item. 완료·접수·연기 = PLAN-work-autogen의 제안행 지연 실체화. 근거키 auto:{종류}:{대상}:{기한}.
  • 차량360 탭 = 기존 Vehicle360(lib/detail-sections.ts 전체 섹션 + history)을 수행창 폭에 맞춰 렌더. 별도 페이지 아님.
  • 모바일 = /m 홈만 교체. 수행창 = /m/vehicle/[plate]를 수행 | 차량360 2탭으로.
  • 토큰: 쿨 뉴트럴(#f6f7f9 / #fff / #0f1218) · 헤어라인 #e2e5ea · r 4/6 · 본문 12px 유지.
